Market-test mechanics

The landing's primary CTA is an email-gated download: visitor enters an email → success state ("link sent") → download points at GitHub Releases. The email is the demand signal; the secondary "Releases ↗" link is the no-friction path. The form in the mockup runs the real state transition so the UX reads true. Live build: host on Vercel; the form POSTs to a small Next.js route (the pseudo-backend) that records the email and returns the release link.
